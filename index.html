SECURITY TIPS

Use a password manager

Unique long passwords for every account. One breach should never open the rest.

Turn on two-factor login

Prefer an authenticator app over SMS. It blocks most account takeovers.

Think before you click

Check the sender and the real link address. Urgent messages asking for codes are phishing.

Keep everything updated

Install system and app updates. Most attacks use bugs that are already fixed.
